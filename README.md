# Commonplace

A simple personal organizer for reminders, income and expenses, lists, moodboards, and notes.

Capture entries are saved locally. Organize non-money items into Spaces, add optional tags to transactions, and edit or delete items from each card's actions menu. Reminder dates and list entries can also be updated.

Removing a Space leaves its items in the Library without a Space. Older saved categories are migrated to Spaces in the browser.

## Run locally

Install dependencies and start the app:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). No account or external service is needed.

Saved items stay in this browser on this device. They do not sync across browsers or devices.
